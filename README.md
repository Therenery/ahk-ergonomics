# AHK Ergonomics

一个 AutoHotkey v2 脚本，给 Windows 补上几处顺手的键盘与鼠标操作：按住 Win 开终端、CapsLock 当修饰键、鼠标侧键扩展。

[English](README.en.md)

## 功能

### 1. 按住左 Win 打开终端

- 按住左 Win 600 ms → 打开 Windows Terminal，里面跑 PowerShell
- 或在 400 ms 内连按两下 Win，第二下按住 → 同样触发（适合把 Win 键当单手热键用）
- 触发时如果焦点在资源管理器窗口，终端直接在该窗口的当前文件夹打开；Win11 多标签页会识别当前激活的那个标签页，不会误用同一窗口里其它标签的路径
- 按住 Win 期间前台窗口变了（说明你在用 Win + 某键），脚本立刻放弃，不抢你的组合键
- 终端起来后自动抢前台，并顺手按 Esc 清掉松开 Win 时弹出的开始菜单

### 2. CapsLock 修饰层

单击 CapsLock 仍然是大小写切换（松手时才切换，不影响组合键）。按住 CapsLock 加其它键则是一层修饰键：

| 按键 | 效果 |
| --- | --- |
| `CapsLock + Q` | 关闭当前窗口（Alt+F4） |
| `CapsLock + E` | 用 Edge 搜索选中内容，没有选中就打开 Edge |
| `CapsLock + W / A / S / D` | 上 / 左 / 下 / 右方向键 |
| `CapsLock + M` | 最小化当前窗口 |
| `CapsLock + F` | 最大化当前窗口 |
| `CapsLock + ,` / `.` | 鼠标左键 / 右键 |
| `CapsLock + ↑` / `↓` | 滚轮上 / 下 |
| `CapsLock + PgUp` / `PgDn` | 鼠标侧键 X1 / X2 |
| `CapsLock + 左键` / `右键` | 上一个 / 下一个虚拟桌面 |

### 3. 鼠标下侧键（XButton1，通常是"后退"）

| 操作 | 效果 |
| --- | --- |
| 单击 | 原生后退 |
| 按住 + 滚轮上 / 下 | 切换虚拟桌面，到头会循环（6 个桌面为例：第 1 个再往左跳到第 6 个） |
| 按住 + 中键 | 任务视图 |
| 按住 + 左键 | 回车 |
| 按住 + 右键 | 退格 |

### 4. 鼠标上侧键（XButton2，通常是"前进"）

| 操作 | 效果 |
| --- | --- |
| 单击 | 原生前进 |
| 按住 + 左键 | 有选中内容则复制；没有选中则只全选，不复制 |
| 按住 + 右键 | 松开右键时粘贴 |

### 5. 上下侧键同时按住：截图

同时按住上侧键和下侧键 → `Win + Shift + S`，弹出系统截图浮层（区域 / 窗口 / 全屏，结果进剪贴板）。单击侧键的后退 / 前进、按住侧键的其它手势都不受影响。

## 环境要求

- Windows 10 / 11
- [AutoHotkey v2.0](https://www.autohotkey.com/) 或更新版本
- Windows Terminal（`wt.exe`），终端快捷键依赖它
- Microsoft Edge，搜索快捷键默认调用它

## 安装

1. 装好 AutoHotkey v2
2. 下载 `ahk-ergonomics.ahk`
3. 双击运行，托盘出现 AutoHotkey 图标即生效
4. 开机自启：`Win + R` 输入 `shell:startup`，把脚本的快捷方式丢进打开的文件夹

## 关于提权

脚本开头会检查管理员权限，没有就以管理员身份重新启动自己，所以每次启动会弹一次 UAC 确认。

需要管理员权限的原因：向以管理员身份运行的窗口发送按键（比如任务管理器、部分安装程序）时，非管理员进程发的键会被 UIPI 拦掉；`Win + Ctrl + 方向键` 切虚拟桌面也受同样限制。

## 配置

脚本里两处常量按自己的习惯改：

```ahk
global totalDesktops := 6   ; 虚拟桌面总数
global currentDesktop := 2  ; 脚本启动时你正停在哪个桌面（从 1 数）
```

搜索快捷键里写死了 `msedge.exe`，想换浏览器就改 `CapsLock & e` 那段里的两处 `Run(...)`。

## 已知限制

- 虚拟桌面的序号靠脚本自己数，只在通过本脚本的手势切换时准确。用 `Win + Tab`、触摸板手势或别的工具切过桌面后，计数会漂移，重启脚本或改 `currentDesktop` 即可复位
- 资源管理器路径识别只认 `CabinetWClass` 窗口，且只在当前位置是真实文件夹时生效（此电脑、回收站、搜索结果等位置会退回用户主目录）
- `CapsLock + E` 依赖 `Ctrl + C` 能否取到选中内容，在终端类应用里通常拿不到
